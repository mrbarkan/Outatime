Outatime

マニュアル。メニューバーでの最初のクリックから、月末にクライアントへ送るレポートまで。Outatimeでできることをすべて説明します。

      はじめに

      Outatime.dmgを最新リリースからダウンロードし、Outatimeを「アプリケーション」にドラッグして開きます。macOS 26 Tahoe以降が必要です。

      OutatimeにはDockアイコンもメインウインドウもありません。小さな時計としてメニューバーに常駐します。時計をクリックするとメニューパネルが開き、記録はすべてここで行います。

      毎朝自動で起動させるには、設定 → 一般でログイン時に開くをオンにします。

      macOSに確認されたら、通知を許可してください。トマトタイマー、ストレッチの通知、「1日の目標を達成」のメッセージは、すべて通知で届きます。

      時間の記録

      アクティビティをクリックすると開始し、もう一度クリックすると停止します。別のアクティビティをクリックすると、現在のものが停止して新しいものが同時に開始されるので、意図しない空白が1日に生まれません。

      6つのアクティビティ

      アクティビティ用途目標に含めるか
      仕事通常の勤務時間。常に含める
      休憩コーヒー、散歩、ちょっとした中断。デフォルトで含める
      昼食食事の休憩。オンにした場合
      残業1日の目標を超えた時間と、週末や休日の作業。常に含める
      移動クライアント先や現場への移動。デフォルトで含める
      外出日中の予約や用事。デフォルトで含める

      何を含めるかは設定 → 記録で選べます。仕事と残業は常に含まれます。

      メモ

      ステータス行の下のフィールドに入力して、Returnキーを押します。メモは実行中のブロックに保存され、いくつでも追加できます。何も実行していないときは、今日の最後のブロックにメモが付くので、終えたばかりの作業も書き留められます。

      動いたままのタイマー

      午前0時になってもタイマーが動いている場合は、そこで区切られて新しい日に引き継がれるので、各日の時間は分かれたままです。パネルには「…から記録中」と表示され、10時間を過ぎると「まだ記録中ですか？」という通知が届きます。この通知は設定 → 記録で変更したりオフにしたりできます。

      クライアント

      複数のクライアントの仕事をしている場合、Outatimeでそれぞれの時間を分けて管理できます。設定 → クライアントでクライアントを追加すると、メニューパネルにクライアントの選択肢が表示されます。

      • クライアントを選ぶと、仕事、残業、移動がそのクライアントの分として記録されます。休憩、昼食、外出はクライアントには属しません。
      • 作業中にクライアントを切り替えると、ブロックはその時点で終わり、新しいクライアントの新しいブロックが始まります。最初の1分以内に切り替えた場合は修正とみなされ、ブロックのラベルが付け替えられます。
      • クライアントを取り除くと選択肢から消えますが、過去のブロックには名前が残り、その月の分も引き続き書き出せます。

      日誌では各ブロックにクライアントが表示され（「仕事 · Acme」）、ブロックの編集画面で変更できます。

      1日の目標

      1日に何時間働くかを設定 → 記録で設定します。Outatimeは、メニューパネル、日誌、レポートのあらゆる場所で実績と目標を比べます。緑の数字は目標より進んでいる時間、赤の数字は足りない時間です。

      • 週末と休日は目標時間がありません。日誌のツールバーにある傘のボタンで休日に設定できます。
      • 今日の不足分は赤で表示されません。1日はまだ終わっていないからです。
      • 時間バンクは、選んだ日付以降の毎日の過不足を合計します。四半期や1年ごとに時間を精算する場合に便利です。

      過不足の下には、今週の目標（1日の目標×その週の勤務日数）の残りと、休日を取るためにあとどれだけ貯める必要があるかがメニューパネルに表示されます。平均、いつもの開始・終了時刻、今月の数値を見るには、日誌のツールバーの統計をクリックします。

      目標達成後は残業

      今日の時間が目標に達すると、実行中の仕事ブロックは達成したちょうどその分で区切られて残業に切り替わり、通知が届きます。週末と休日の作業はすべて残業です。手動で切り替えたい場合は、設定 → 記録でオフにできます。

      日誌

      メニューパネルから開きます。サイドバーにはその月が1日ずつ並び、各日の時間、内訳を示すバー（バー上の目盛りが目標です）、月の過不足、週ごとの合計が表示されます。日を選ぶとタイムラインで表示されます。

      ブロックの編集

      • ブロックは5分単位で、隣のブロックの端に吸着します。端をドラッグすると、そのブロックだけのサイズが変わり、次のブロックの手前で止まります。接している2つのブロックの境目を動かすには、⌥を押しながらドラッグします。
      • 空いている場所をダブルクリックするか、ツールバーの＋ボタンを使うとブロックを追加できます。追加されるのは1時間の仕事で、次のブロックと重ならないよう、その手前で止まります。
      • 編集画面では、⌥ Returnでメモを改行でき、時間のステッパーで終了時刻を5分単位で動かせます。
      • ブロックは編集画面から削除できます。

      複数のブロックをまとめて

      ⌘を押しながらブロックをクリックすると選択でき、⇧を押しながらクリックすると、最後にクリックしたブロックからそのブロックまでの間をすべて選択できます。⌘ Aでその日のすべてのブロックを選択し、Escで選択を解除します。選択したブロックを右クリックすると、クライアントの設定、アクティビティの変更、削除ができます。クライアントを設定できるのは、仕事、残業、移動のブロックだけです。

      テンプレート

      毎日の流れが似ている場合は、日誌で1日分を整えてから、テンプレート → この日をテンプレートとして保存を選びます。同じメニューから、ほかの日に適用できます。すでにブロックがある日にテンプレートを適用すると、置き換える前に確認されます。

      移動のしかた

      ツールバーの矢印か、⌘ [と⌘ ]で1日ずつ移動し、⌘ Tで今日に戻ります。タイムラインは⌘ −と⌘ =で拡大・縮小できます。

      集中と休憩

      トマトタイマー

      メニューパネル上部のタイマーボタンをクリックするとオンになります。仕事が開始され、25分の集中ラウンドと5分の休憩を繰り返し、4ラウンドごとに15分の休憩が入ります。メニューバーにはラウンドの残り時間が表示されます。

      ラウンドが終わると、通知に休憩を開始または仕事に戻るが表示され、記録を切り替えてくれます。昼食、移動、外出の間は、戻るまで一時停止します。各時間の長さは設定 → トマトタイマーで変更できます。

      ストレッチの通知

      仕事または残業を50分続けると、Outatimeが立ち上がるよう知らせます。クライアントを切り替えてもリセットされませんが、休憩を取るとリセットされます。トマトタイマーの休憩で体を動かせるので、トマトタイマーがオンの間は通知しません。間隔の変更やオフは設定 → 記録で行えます。

      レポート

      メニューパネルからは今月の分を、日誌のツールバーからは表示中の月の分を書き出せます。

      書き出し内容
      月次レポートExcelブック。1日1行で過不足を示すサマリー、クライアント別の時間、すべてのブロック。
      クライアントレポート請求用の、1クライアントの1か月分。1日ごとの時間とその内訳のブロック。目標や過不足は含みません。
      マスターブック使い始めてからのすべて。開くと、月ごとの時間、過不足、アクティビティのダッシュボードが表示されます。
      日別サマリー1日1行のCSV。Numbers、Notionなどで使えます。
      項目その月のすべてのブロックを含むCSV。

      月次レポートの行はマスターブックの表の下に貼り付けられ、ダッシュボードに反映されます。マスターブックをバージョン1.2より前に作成した場合は、先に新しく書き出してください。ブロックにクライアント列が加わっています。

      設定

      メニューパネルの•••メニューから設定を開くか、パネルを開いた状態で⌘ ,を押します。

      一般ライトまたはダーク、言語（English、Español、Português、Français、Deutsch、Italiano、日本語、简体中文）、メニューバーの表示内容、メニューバーアイコンのカラー表示、ログイン時に開く、アップデート。
      記録1日の目標、目標に含めるもの、時間バンク、目標達成後は残業、リマインダー、グローバルショートカット。
      クライアントクライアントの追加、名前の変更、取り除き。
      トマトタイマー集中、短い休憩、長い休憩の長さ。

      メニューバーの表示内容

      実行中のアクティビティのアイコンと経過時間、アイコンのみ、時間のみ、または今日の目標までの残り時間を選べます。カラーのアイコンをオフにしない限り、アイコンはアクティビティの色になります。

      アップデート

      Outatimeは新しいバージョンを自動で確認し、その場でインストールします。ダウンロードページに再びアクセスする必要はありません。すぐに確認したいときは、設定 → 一般 → アップデートを確認を使います。アップデート後は、新機能ウインドウに変更点が表示されます。

      ベータ版のアップデート

      設定 → 一般でベータ版のアップデートを受け取るをオンにすると、次のバージョンの先行ビルドを受け取れます。不完全な部分があるかもしれません。もう一度オフにすると、次の正式リリースから通常のリリースに戻ります。

      データについて

      Outatimeが保持するデータは、すべてMac上の1つのファイルにあります。どこにも送信されません。Outatimeがオンラインになるのは、アップデートを確認するときだけです。

      ~/Library/Containers/com.dbarkan.Outatime/Data/Library/Application Support/Outatime/data.json

      履歴をバックアップするには、このファイルをコピーします。万一ファイルを読み込めない場合、Outatimeは上書きせずに、元のファイルの隣にdata.json.broken-と番号を付けた名前で退避し、新しく始めます。

      キー動作

      ⌃ ⌥ ⌘ Bどのアプリからでも休憩を開始・停止
      ⌘ [ ⌘ ]日誌で前日・翌日へ移動
      ⌘ T日誌で今日に戻る
      ⌘ − ⌘ =日誌のタイムラインを拡大・縮小

      ほかのアプリと重なる場合は、設定 → 記録でグローバルショートカットをオフにできます。

      うまくいかないとき

      通知が届かない

      システム設定 → 通知 → Outatimeを開き、通知を許可してください。トマトタイマー、リマインダー、「1日の目標を達成」は、すべて通知を使います。

      メニューバーに時計が見当たらない

      メニューバーが混み合っていると、macOSは収まらない項目を隠します。カメラのノッチの横では特にそうです。メニューバーに置く必要のないアプリを終了するか、⌘を押しながら時計を右側へドラッグしてください。

      1日の時間が正しくない

      日誌でその日を開いてブロックを直します。ドラッグしたり、サイズを変えたり、クリックして正確な時刻を入力したりできます。過不足とレポートはすぐに更新されます。

      その他の問題

      GitHubでIssueを作成し、何が起きたかを説明してください。
