Outatime

使用手册。Outatime 的全部功能，从在菜单栏中的第一次点按，到月底发给客户的报告。

      开始使用

      下载 Outatime.dmg（位于最新版本页面），将 Outatime 拖到“应用程序”文件夹，然后打开它。需要 macOS 26 Tahoe 或更高版本。

      Outatime 没有程序坞图标，也没有主窗口。它以一个小时钟的形式待在菜单栏中。点按时钟即可打开菜单面板，所有记录都在这里完成。

      如果想让它每天早上都准备就绪，请在“设置”→“通用”中打开登录时打开。

      macOS 询问时，请允许通知。番茄钟、伸展提醒和“达到目标”消息都会以通知的形式出现。

      记录时间

      点按一项活动即可开始记录，再次点按即可停止。点按另一项活动会在同一时刻停止当前活动并开始新活动，因此你的一天不会出现意料之外的空档。

      六项活动

      活动用途是否计入目标
      工作正常工作时间。始终计入
      休息喝咖啡、散散步、短暂停歇。默认计入
      午餐用餐时间。打开后计入
      加班超出每日目标的时间，以及周末和休息日的工作。始终计入
      出差前往客户处或现场的路上。默认计入
      外出白天的预约和私事。默认计入

      在“设置”→“记录”中选择计入哪些活动。工作和加班始终计入。

      备注

      在状态行下方的输入框中输入内容，然后按下 Return 键。备注会存储在当前运行的时段上，数量不限。没有活动在运行时，备注会添加到今天的最后一个时段，方便你随手记下刚完成的事情。

      未停止的计时器

      午夜时仍在运行的计时器会在零点被切开，并在新的一天继续运行，因此每一天都保留各自的时长。面板会显示“自…起运行中”提醒你；运行超过十小时后，你会收到“仍在记录吗？”通知。可在“设置”→“记录”中更改或关闭此提醒。

      客户

      如果你同时为多个客户工作，Outatime 可以分别记录他们的工时。在“设置”→“客户”中添加客户后，菜单面板中就会出现客户选择器。

      • 选择客户后，工作、加班和出差都会计入该客户。休息、午餐和外出从不属于任何客户。
      • 工作时切换客户，当前时段会在此刻结束，并为新客户开始一个新时段。如果在第一分钟内切换，Outatime 会将其视为更正，直接更改该时段的客户。
      • 移除客户后，该客户会从选择器中消失，但过去的时段仍保留其名称，你也仍可导出其月度数据。

      在日志中，每个时段都会显示其客户（“工作 · Acme”），你可以在时段编辑器中更改。

      每日目标

      在“设置”→“记录”中设定你每天计划工作的小时数。Outatime 会在各处将你完成的时长与目标进行对比：菜单面板、日志和报告中都有。绿色数字表示超前，红色数字表示落后。

      • 周末和休息日没有应工作时长。使用日志工具栏中的雨伞按钮标记休息日。
      • 今天永远不会以红色显示为落后。因为这一天还没有结束。
      • 工时结余会累计从你选定的日期起每一天的结余，适合按季度或按年度结算工时的情况。

      达标后计为加班

      当今天的时长达到目标时，正在运行的工作时段会自动切换为加班，切换点精确到达标的那一分钟，同时你会收到通知。在周末和休息日，所有工作都计为加班。如果你更喜欢手动切换，可在“设置”→“记录”中关闭此功能。

      日志

      从菜单面板打开日志。边栏按天列出整个月，显示每天的时长、一条显示当天构成的条形图、当月结余以及每周合计。选择某一天即可以时间线方式查看。

      编辑时段

      • 时段会以五分钟为单位对齐，并吸附到相邻时段的边缘。相接的时段会一起移动：拖移共用的边缘，两个时段都会改变。
      • 在空白处连按两次，或使用工具栏中的 + 按钮，即可添加时段。新时段为一小时的工作，遇到下一个时段时会停止，不会与之重叠。
      • 在编辑器中，按 ⌥ Return 可在备注中换行；时长步进器以五分钟为单位调整结束时间。
      • 在时段的编辑器中可删除该时段。

      模板

      如果你的每一天大同小异，可以先在日志中安排好一天，然后选取“模板”→“将这一天存储为模板”。之后可从同一菜单将其应用到其他任意一天。如果目标日期已有时段，应用模板前会先询问是否替换。

      浏览

      使用工具栏中的箭头或 ⌘ [ 和 ⌘ ] 逐日前后移动，按 ⌘ T 回到今天。使用 ⌘ − 和 ⌘ = 缩放时间线。

      专注与休息

      番茄钟

      点按菜单面板顶部的计时器按钮即可打开番茄钟。它会开始记录工作，以 25 分钟专注、5 分钟休息为一轮，每四轮后休息 15 分钟。菜单栏会显示本轮的倒计时。

      一轮结束时，通知会提供开始休息或回到工作，并替你切换记录。午餐、出差和外出会让番茄钟暂停，直到你回来。可在“设置”→“番茄钟”中更改各项时长。

      伸展提醒

      连续工作或加班 50 分钟后，Outatime 会提醒你起身活动。切换客户不会重置计时，休息才会。番茄钟打开时它不会打扰你，因为番茄钟的休息已经让你动起来了。可在“设置”→“记录”中更改间隔或将其关闭。

      报告

      从菜单面板导出当前月份，或从日志工具栏导出你正在查看的月份。

      导出包含内容
      月度报告一个 Excel 工作簿：包含每天一行及其结余的汇总、每个客户的时长，以及所有时段。
      客户报告用于开票的单个客户月度数据：该客户每天的时长及对应的时段，不含目标和结余。
      主工作簿自你开始使用以来的全部数据，打开后首先显示按月汇总时长、结余和活动的仪表板。
      每日汇总每天一行的 CSV，可用于 Numbers、Notion 或其他任何工具。
      记录包含当月所有时段的 CSV。

      月度报告中的行可以粘贴到主工作簿的表格下方，仪表板会自动纳入这些数据。如果你的主工作簿是在 1.2 版之前创建的，请先重新导出一份：时段现在多了“客户”列。

      设置

      从菜单面板中的 ••• 菜单打开“设置”，或在面板打开时按下 ⌘ ,。

      通用浅色或深色外观、语言（English、Español、Português、Français、Deutsch、Italiano、日本語、简体中文）、菜单栏显示内容、彩色菜单栏图标、登录时打开，以及更新。
      记录每日目标、计入目标的活动、工时结余、达标后计为加班、提醒和全局快捷键。
      客户添加、重命名和移除客户。
      番茄钟专注、短休息和长休息的时长。

      菜单栏显示内容

      可以显示正在运行的活动图标及其已运行时长，或仅显示图标，或仅显示时间，或显示今天距离目标还差多少。图标会采用活动的颜色，除非你关闭彩色图标。

      更新

      Outatime 会自动检查新版本并直接安装，你无需再访问下载页面。如需立即检查，请前往“设置”→“通用”→“检查更新”。更新后，“新功能”窗口会列出更改内容。

      Beta 版更新

      在“设置”→“通用”中打开获取 Beta 版更新，即可收到下一版本的早期构建。它们可能还不够完善。再次关闭后，你会在下一个正式版本发布时回到正式版。

      你的数据

      Outatime 掌握的所有信息都保存在你 Mac 上的一个文件中。不会向任何地方发送数据；Outatime 唯一联网的时候是检查更新。

      ~/Library/Containers/com.dbarkan.Outatime/Data/Library/Application Support/Outatime/data.json

      拷贝此文件即可备份你的历史记录。如果文件无法读取，Outatime 会将其另存在原文件旁边，命名为 data.json.broken- 加一个数字，然后重新开始，而不会覆盖它。

      键盘快捷键

      按键作用
      ⌃ ⌥ ⌘ W在任意 App 中开始或停止工作
      ⌃ ⌥ ⌘ B在任意 App 中开始或停止休息
      ⌘ [ ⌘ ]在日志中前往前一天或后一天
      ⌘ T在日志中前往今天
      ⌘ − ⌘ =缩放日志时间线
      ⌘ ,在菜单面板中打开“设置”
      ⌘ Q在菜单面板中退出

      如果全局快捷键与其他 App 冲突，可在“设置”→“记录”中将其关闭。

      遇到问题时

      收不到通知

      打开“系统设置”→“通知”→“Outatime”，然后允许通知。番茄钟、各类提醒和“已达到每日目标”都依赖通知。

      菜单栏中看不到时钟

      菜单栏项目过多时，macOS 会隐藏放不下的项目，尤其是在摄像头所在的刘海旁边。退出一个不需要显示在菜单栏中的 App，或按住 ⌘ 将时钟向右拖移。

      某一天的时长不对

      在日志中打开这一天并修正时段：拖移、调整长短，或点按某个时段输入准确时间。结余和报告会立即更新。

      其他问题

      在 GitHub 上提交问题，并描述发生了什么。
